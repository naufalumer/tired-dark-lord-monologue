A 100-word monologue for a fantasy villain who is secretly just very tired: three hundred years keeping his mountain, and he keeps losing the thread mid-threat, drifting to the quiet before the horns and the porridge before the sieges, before the sting lands in the last line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
